# Storage Agent v1.01.0

v1.01.0 reconstructs Storage Agent as a native Agent window. v1.00 deleted
copilot SKUs but kept a workbench/command-center shell. This release replaces
that shell. No new model capabilities, no storage tools, no migration (head
remains **027**).

## Deleted from the product

- Task **header**, **Focus** presentation, and **live execution strip**.
- Command-center **queues**, sidebar **search**, **pin / duplicate / archive**.
- Persistent **sidecar-health footer**.
- **ThinkingBubble** invented stages and the in-document **Execution Summary**
  wall (tokens, budget, CallDetail under every Work Result).
- Direction **Branch / Redirect / Rerun**.
- Attach-type **SKU chips**. Type is inferred from the filename.
- Review **document hero** and side-column application chrome.
- Unused **AgentMemory** panel, **BrandMark**, activity-density preference, and
  calendar day-bucket navigation. Leftover wizard / slash-SKU / price-table /
  pin-archive copy.

## Changed

- Empty window is the Composer. The center is one readable work record.
- Real tool rows live in that record (streaming and after it lands).
- Sidebar is quiet titles. Settings is hidden behind an icon.
- Review is a light overlay: title, close, artifact.
- Figures and provenance sit inside the latest Work Result.
- Artifact links appear only when Evidence, Execution, or a Report exists on
  that result. Report opens from the latest Work Result.

## Preserved

- One Composer: Delegate / Steer / Stop.
- Agent Task as the application.
- Real Decision gates, queued Direction, Resume.
- Sidecar engines (cost sim, Remediation Plan, baseline/Drift, revisit) with
  no product UI entry.
- Read-only storage tools. Migration head **027**.

## Security

Unchanged. No new tools, no migration past **027**.
