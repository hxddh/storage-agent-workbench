# Storage Agent v1.15.0

**True Native Agent — no chat placeholders, no painted hints, no footer policy fact, no manual transport chrome; search is painted; tables fit first; usage speaks one vocabulary. No migration (head stays 030).**

## Summary

v1.14.0 made the interaction honest. v1.15.0 makes the window native: the Composer delegates in work language (`Describe the storage work to delegate…`), the empty start is exactly one static greeting line plus the Composer, the sidebar footer is Settings alone, stalled streams heal themselves with a quiet reconnecting line instead of a Resync button, Find (⌘F) and the palette (⌘K) have visible title-bar and document entries with CJK single-character search, tables fit when they fit and hint only when truly wide with paginated long tables, and token/context usage renders from one vocabulary (`lib/usage`) where cached is a subset, partial reports wear `~`, and silence is named instead of vanishing. Settings stacks on narrow widths with strict CJK breaks; the Composer and user bubble carry real elevation.

## Review of v1.14.0 (what this release corrects)

- **Chat placeholders.** `Ask about your storage… / 问问你的存储…` was chatbot hospitality, not Direction language.
- **Painted hints.** The rotating `Try: / 试试：` line violated the product's own "no suggestion grid" rule and named work (`巡检`) the user never did.
- **Footer policy fact.** The sidebar `只读` fact wrapped/clipped to `之读` at narrow widths and competed with the task list; no native app paints policy in the sidebar.
- **Manual transport.** A stalled stream asked the user to press Resync although the protocol is push-driven with `after=<seq>` recovery.
- **Unpainted search.** Find and the palette were keyboard-only; a native window paints its search. CJK single characters (`桶`) could not be searched at all.
- **Punishing tables.** `w-max` forced every table to scroll sideways, even two columns that fit; numeric `whitespace-nowrap` forbade wrapping.
- **Three disagreeing numbers.** Execution detail, the Composer meter, and compaction toasts each formatted usage differently; cached double-counted as an additive sibling; silence vanished.
- **Hardcoded copy.** Execution/Find/Skills strings bypassed the i18n dict, the mixed-language source.
- **Settings wrapping.** Two-column grids squeezed long CJK hints into orphans with no kinsoku rules.
- **Flat craft.** Hairline-only depth with no elevation next to Codex.

## What changed

- **Work language** (`Composer.tsx`, `startGreeting.ts`): static single greeting per language; delegate/steer placeholders describe work; hint line and `START_HINTS` painting removed (deprecated aliases stay empty, never rendered).
- **Sidebar truth** (`AgentTaskNavigation.tsx`, `navigationCopy.ts`): footer is Settings alone; `sidebar-readonly` selector retained as deprecated `display:none`.
- **Search painted** (`App.tsx` title bar, `TaskDocument.tsx` document entry, `taskFind.ts`/`FindBar.tsx`): `titlebar-find`, `titlebar-palette`, `task-find-open`; `minQueryFor`/`meetsMinQuery` (CJK 1, Latin 2).
- **Transport heals itself** (`TaskDocument.tsx`, `taskCopy.ts`): stalled renders `task.reconnecting` status with a 2 s auto-retry; `stalled`/`reload` copy removed; earlier history auto-loads near the top (buttons remain as fallback/E2E hooks).
- **Tables fit first** (`MarkdownImplementation.tsx`, `native-document.css`): fluid `w-full` with wrapping cells; `wide` heuristic (cols > 4 or cell > 60) adds border + scroll hint; > 30 rows paginate with expand.
- **One usage vocabulary** (`lib/usage.ts`, `ContextMeter.tsx`, `ExecutionDetailImplementation.tsx`, `useCompactContext.ts`): `fmtTokensUnified`, `formatUsageLine` (cached as `incl.`), `contextReading` (`none`/`unreported`/`measured` + `estimated`/`floor`); meter paints an unreported badge instead of vanishing.
- **Copy in the dict** (`i18n.tsx`): `task.*`, `find.*`, `exec.*`, `usage.*`, `table.*`, `skills.*`; `ExecutionDetail`/`FindBar`/`NativeAgentPanel` read `t()`.
- **Settings truth** (`index.css` kinsoku, `native-shell.css` wrap, panes `sm:grid-cols-2`).
- **Elevated craft** (`index.css` real shadows, Composer card + bubble elevation + top-right tail radius).
- **Prompt**: the model no longer pitches engines in prose; the palette names them.

## Preserved

- One durable Agent Task runtime; one submit path; sequence-only recovery; steer/stop/resume/verify/revisit semantics; read-only allowlist, vault, redaction, server-side scope, bounded/sanitized context, explicit Decisions, no chain-of-thought persistence. No migration.
