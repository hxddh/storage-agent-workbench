# Storage Agent v1.11.0

**Codex parity all the way down — a transcript turn, approvals raised inline by the gated tool, an Artifacts panel, and the runtime split by responsibility. Migration 029.**

## Summary

v1.10.0 made the shell native. v1.11.0 makes the *work* read like a native Agent's. A turn is now what Codex shows: the user's message as a bubble, the model's short commentary before it acts, one collapsed *Worked for …* group of tool rows, an approval card exactly where the gated tool asked for one, and then the answer as plain Markdown. The model no longer writes a metadata JSON block or a list of "next-action proposals"; the "Decision required" card that appeared out of nowhere is gone. The only confirmation boundary is the `import_evidence` tool, which pauses the Execution and resumes it on **Allow**. Review is an Artifacts panel beside the transcript. The 2,700-line `session_agent.py` is eight modules.

## Review of v1.10.0 (what this release corrects)

- **The Work Result was one buffer.** Everything the model said — commentary before tool calls and the answer — was concatenated and streamed as one page, and the persisted answer replaced it on reload. Unreadable.
- **A mandatory ```json contract block** ended every answer; a held-back fence, a "contract sentinel", and a JSON-example heuristic guarded it in the stream.
- **"Decision required" came from prose.** The model's `next_action_proposals` were promoted to durable Decisions; approving opened a second dialog that planned → confirmed → ran the import by hand.
- **The document was not a transcript**: a grey Direction block with copy chrome, artifact chips, a fading table with a "Show chart" toggle, a metrics footer, a 64rem data track.
- **Review was a modal sheet**, not a panel beside the work.
- **One 2,677-line runtime module.**

## What changed

- **Runtime turn model** (`sidecar/app/agent_runtime/stream.py`): per-segment sanitized streaming; `message.completed` frames close a commentary segment (`final: false`) or the answer (`final: true`); the Work Result carries `turn_items` (ordered `message` / `tool` items) persisted on `session_messages.turn_items` (migration 029). Grounding is **derived** from the tool trace (`read_skill`, evidence tools, `note_open_question`), never claimed. `skills/contract.py`, the sentinel holdback, and the continue-investigation proposal are gone; a cut-short turn is marked `cut_short` and says so in its text.
- **Inline approvals** (`agent_runtime/gated_tools.py`, `task_runtime/runtime.request_approval`, `evidence/import_service.py`): `import_evidence` plans through the same bounded service the `/evidence-imports` API uses, opens a durable Decision (`kind=approval`) with the projected impact, appends `approval.opened`, sets the Execution `waiting`, and blocks (no wall-clock timeout; Stop withdraws it as declined). `decisions/{id}/resolve` takes `scope: once | task`; **Allow for this task** records later calls of the same `action_type` as already-approved Decisions (`approval.granted`). Proposal-derived Decisions, `DECISION_GATED_ACTION_TYPES`, `open_decisions_from_proposals`, and the resolve-time prepare hand-over are removed; `/sessions/{id}/actions/prepare` stays as a compatibility endpoint.
- **Runtime split**: `session_agent.py` (entry: agent builder, streamed run, `SESSION_LOOP`, `answer`, `build_stream`, re-exports) + `limits`, `prompt`, `guards`, `steer`, `usage`, `finalize`, `stream`, `gated_tools`.
- **Transcript document** (frontend): one `Turn` renderer for durable and live turns — right-aligned user bubble, commentary segments, collapsed *Worked for …* group with live elapsed, inline approval card (**Allow · Allow for this task · Deny**), Markdown answer with tables scrolling in their own container. `AgentDecisionCard`, `EvidenceImportDialog`, `ExecutionMetrics`, the data track, chip rows, the table fade and chart toggle are deleted.
- **Artifacts panel**: a right split (⌘I) listing Evidence, Reports, Remediation Plans, Baselines/Drift, and Execution detail as a document; replaces the Review sheet.
- **Shell**: sidebar day groups (Today · Yesterday · dated), a quiet Read-only label, Esc stops when the Composer is empty, a context meter next to the model chip (from `metrics.context_window`), a rotating greeting, window position/size restored by `tauri-plugin-window-state`, EN/ZH parity.

## Preserved

- One durable Agent Task runtime; one submit path; sequence-only stream recovery; steer/stop/resume/verify/revisit semantics; runtime titles; reasoning effort.
- Read-only allowlist, vault, redaction, server-side scope, bounded/sanitized context, no chain-of-thought persistence. The import path is the same plan → confirm → run with the same `approval_events` and audit rows; it now runs from a tool the user approves instead of a dialog.
