# Storage Agent v0.96.0

v0.96.0 turns Storage Agent from one-shot storage diagnosis into a
**quantified storage-optimization copilot and ongoing caretaker**.

The product invariant is unchanged:

> **The Agent Task is the application.**

Canonical work model:

> **Direction → Execution → Decision (when required) → Work Result → Artifact**

v0.94/v0.95 shipped and made visible the durable Task/Execution/Decision/Work
Result/Artifact runtime. This release spends that runtime on user-visible
storage value: a one-year cost projection, a pasteable repair plan, one-click
read-only Verify, and a scheduled revisit that reports Drift — all on the same
Task, all read-only, every number with coverage.

## What this release completes

- **Cost/lifecycle simulator.** Pure functions over bounded inventory
  aggregates, lifecycle facts, and a local price table. Class mix is projected
  over 0/30/90/180/365 days. Dollar deltas are labelled estimates with
  coverage, or withheld when inventory is missing or the price table is still
  the example schedule.
- **Remediation Plan Artifact.** Typed, versioned, with pasteable lifecycle
  JSON, finding/Evidence refs, simulator impact, and a verification checklist.
  The user applies it in their own console/CLI. Storage Agent never writes to
  the bucket.
- **Verify.** A Task-area action that submits `kind=verify` through the one
  runtime path, diffs live read-only configuration against the plan, and writes
  `proposed` / `verified` / `partially_verified` / `stale`.
- **Baselines and Drift.** A baseline is a bounded snapshot, not raw rows.
  Drift classifies findings added / resolved / still present, diffs
  configuration, and reports a two-point trend. No baseline → an explicit gap.
- **Scheduled revisits.** Optional per-task interval. When the Sidecar is
  running and a visit is due, `runtime.submit(kind=revisit)` runs a read-only
  re-check. Catch-up after the app was closed is labelled. Decisions are never
  auto-approved. The user can turn the schedule off.
- **Productization.** Ready-to-delegate suggestions map to checkup / cost
  review / drift check. Review Overview shows plan, baseline, Drift, and
  revisit without a new navigation surface.
- **Runtime hygiene.** Periodic SQL-set `execution_events` prune (same
  terminal-only / dual-cap / truncation-marker contract). One pending Decision
  per `(task, action_type)`.

## What this release does not change

- Single Agent, read-only autonomy, explicit Decision boundaries.
- No shell/terminal/browser/mutation tools, no CoT in the event log, no secrets
  in prompts.
- `/sessions` compatibility shims, `(task, turn_id)` idempotency,
  `after=<last seq>` recovery, Steer/Stop/Resume semantics.
- No new top-level navigation, no workflow canvas, no second Agent.
- ORC inventory is not in this release and is not a near-term roadmap item.

Migration head is **027**.
