# Storage Agent v1.14.0

**Interaction truth and content craft — the waiting-state steer lands where it belongs, queued work edits, usage renders, and figures speak both languages. No migration (head stays 030).**

## Summary

v1.13.0 made the runtime honest. v1.14.0 makes the interaction honest and the content finished: a steer raised while an approval is open acts on the waiting execution instead of silently re-queuing; queued Directions edit until they run; Execution detail shows measured usage; figures, evidence states, and triage read localized; times read relative with UTC on hover; typing past the server's length caps is refused with the reason instead of dying as a 422; tables size themselves with a copy; baselines open as documents instead of JSON walls; the empty start names one engine question a day.

## Review of v1.13.0 (what this release corrects)

- **Waiting-state steer fell through.** `active_execution` excluded `waiting`, so steering during an open approval 409'd and the client re-submitted it as a queued follow-up — guidance for the pending decision that would run after it.
- **Queued work was cancel-only.** A typo in a queued Direction meant cancel and re-queue.
- **Usage was invisible.** Token counts persisted per turn but surfaced nowhere in the product UI.
- **Figures spoke English only.** ~25 hardcoded strings across the viz layer, plus raw severity tokens and a hardcoded `"ready"`.
- **Times misled.** Bare UTC slices read as local time; sidebar relative times froze on idle windows.
- **Inputs had no ceiling.** Pastes beyond the server caps failed as bare 422s; renames were unbounded.
- **Overlays leaked focus.** The collapsed sidebar kept tab stops; the overlay Artifacts panel and model menu had no keyboard contract.
- **Outlines, ids, tables.** Anchors missed the nested scroller; duplicate headings collided; tables had no size or copy.
- **Engines were undiscoverable.** Nothing in the product said cost plans, baselines, or reports could be asked for.
- **Four clipboards.** The same copy logic hand-rolled in four components.

## What changed

- **Steer reaches waiting** (`runtime.steerable_execution`): running/queued first, else a live waiting execution — delivered post-decision or carried forward on decline. Pinned by `test_v114_interaction.py`.
- **Editable queue**: `PATCH .../executions/{eid}` (409 past the queue), audited; queued rows edit inline (Enter saves, Esc closes).
- **Usage rows**: detail matches the Work Result to `turn_metrics`, renders reported fields only.
- **Localized content**: viz/evidence/triage through i18n (EN/ZH), one `SeverityMark`, drift/config copy honest about backend strings staying as-is.
- **Honest times**: shared `lib/time.ts` (DST-safe), relative everywhere with UTC on hover, minutely ticker.
- **Bounded inputs**: Composer counter past 75 % (8 000 steer / 32 000 direction caps), refuse past 100 %; rename capped at 120.
- **Keyboard truth**: `inert` collapsed sidebar, trapped overlay panel, listbox model menu with arrows/Enter.
- **Document craft**: outline for two sections with smooth in-scroller jumps, unique heading ids, editorial h1/h2 weights, table size + TSV copy, baselines as findings + folded raw JSON with copy, yaml/toml/ini highlighting.
- **Discoverability**: daily rotating engine hint on the empty start; the model offers engines in one sentence when relevant (prompt).
- **One clipboard** (`hooks/useCopy.ts`); toast comment corrected; RankedBars keys; unified chart geometry.

## Preserved

- One durable Agent Task runtime; one submit path; sequence-only recovery; steer/stop/resume/verify/revisit semantics; read-only allowlist, vault, redaction, server-side scope, bounded/sanitized context, explicit Decisions, no chain-of-thought persistence. No migration.
