# Storage Agent v1.19.0

**Document-native window: the Task reads as a document, not a message exchange. No migration (head stays 030).**

## Summary

v1.18.0 made the runtime underneath the window native. v1.19.0 reviews the **rendered** window. The review covered all 55 real-Sidecar gallery states, in both themes and both languages. It was held against one bar: native, simple, elegant, and not a message-exchange tool. The central change is the shape of a turn. It is now a section of the Task document, headed by the user's Direction in their own words, with the Agent's work and Work Result beneath it. It is no longer a right-aligned bubble answered on the left.

## Review of v1.18.0 (what this release corrects)

- **Turns looked like a message exchange.** Each turn showed a right-aligned bubble with the reply on the left.
- **The model chip was confusing.** Its icon was a crescent moon, and "No model" was painted in warning yellow on every screen.
- **Colour carried meaning in text, not just in marks:**
  - a red "Needs attention" sentence in the title bar;
  - a red paragraph for the runtime-unavailable banner;
  - Drift counts coloured orange, green and blue.
- **The command palette looked unfinished:**
  - it faded its own opacity while covering readable text;
  - its input drew an inner focus box;
  - shortcuts ran together as `CtrlN`.
- **"Jump to latest" was see-through** over the document.
- **Execution detail had several problems:**
  - two Back controls;
  - the Direction repeated under the title;
  - body text was larger than the headings;
  - status appeared as lowercase coloured text;
  - usage wrapped behind a stray separator.
- **Raw values leaked into the UI:**
  - tool rows repeated their target (`head_bucket bucket-1 bucket-1`);
  - the approval scope read `max 268435456 bytes`, in English inside the Chinese card;
  - provenance previews repeated the tool's snake_case name.
- **Figures read like a debug panel.** Charts floated in empty space, the cost chart had no legend, and the dollar delta was set in monospace.
- **Sidebar rows were noisy.** Every row repeated a relative time already given by its day group.

## What changed

- **A turn is a document section.**
  - The Direction (`.turn-direction-text`) is a left-aligned 16px/560 heading with no fill, no radius and no bubble.
  - Later turns open with a hairline.
  - Hover actions sit in the gap under the heading and reserve no row.
- **Native type.** The platform UI face comes first (SF Pro on macOS, Segoe UI Variable on Windows); vendored Inter is the fallback.
- **Status lives in one dot.** This covers title-bar state, banners, the model chip ("No model" plus a dot), Execution-detail status and drift cells. Text stays ink.
- **Palette.** An opaque raised sheet with a transform-only entry, focus drawn by the sheet, key caps, and a fade at the end of the list.
- **Execution detail.**
  - One Back control: the panel's.
  - The Direction block appears only when it adds to the title.
  - Sentence-case status, with a middot-separated meta line and usage on its own line.
  - Result prose steps down so headings stay above body text.
- **Truer details.**
  - `argSummary` drops values equal to the row's target.
  - `formatScanScope` localizes the approval scope and humanizes sizes; gate reasons are localized.
  - `humanizeTool` names provenance tools once, in words.
- **Figures.**
  - Legends sit above the plots, and the cost chart gains its baseline/candidate legend.
  - Stacked segments get a 2px surface gap.
  - Single-series bars are achromatic ink.
  - Drift counts are ink in hairline cells.
  - The dollar delta is a sans headline, and byte deltas are humanized.
- **Sidebar and Composer.**
  - Sidebar rows are titles only.
  - The document fades under the Composer dock.
  - The plan card is a flat checklist on the same hairline rule as the Worked group.
- **One Direction, painted once.** A Direction delegated to an idle task is briefly `queued` before the supervisor starts it. The live heading already is that Direction, so the queue head is not repeated as a queued row. Work genuinely queued behind a running execution still shows as queued.

## Preserved

- The window structure: sidebar · title bar · one Task document · one Composer.
- One Composer (Delegate · Steer · Stop), Artifacts beside the document, and approvals inline where the gated tool raised them.
- The runtime, API and security floor, all unchanged from v1.18.0. No migration.

## Contracts

- `architecture.test.ts` and `v117.test.tsx` now assert that the Direction is an unfilled, unrounded, left-aligned heading, that later turns get a hairline, and that no `turn-user-bubble` remains.
- The documentation contract is at v1.19.0 and forbids "right-aligned bubble" in current docs.
- `ApprovalCard.test.tsx` covers `formatScanScope`.
- The focus-ring allowlist adds the palette, whose sheet draws the focus.

## Verification performed

- **Frontend:** typecheck clean, Vitest 628 passed, production build green.
- **Real-Sidecar Playwright E2E:** 172 passed.
- **Visual-review gallery:** all 55 states recaptured and reviewed after the changes.
- **Not run:** manual release smoke on physical macOS/Windows/Linux machines.

## Known gaps

- The *Jump to latest* pill still floats over whatever row sits beneath it. It is now opaque, but it is not reserved space.
- Figures have no hover layer yet.
- The system font means type metrics now differ slightly per platform. That is intended.
