# Storage Agent v11.0.0

**The run made legible.** v11 is an Agent-native presentation release on the same v10 runtime: one Agent, one submit path, one item stream, 15 read-only tools, no migration. The window now shows the work while it happens, renders the deterministic results the tools returned, and lets a finding point back at the checks that produced it.

## The work is the interface

- **Home is an empty Task.** The same title bar, document and docked Composer as every conversation. No hero, editorial eyebrow, starter cards or second estate page. The one heading, three quiet prompt chips, *Needs attention* and the account lines sit in the reading column; a chip only fills the Composer.
- **One Composer, one position.** The Composer is docked in the same place on Home and every task. `@` opens one searchable estate picker for accounts, buckets and open Issues. Selected refs become chips; a chip or a file makes a new, queued Direction, never a steer. Context is focus, not authorization: the account's bucket/prefix scope is still enforced server-side.
- **The run is visible.** While a Turn is live the run trace is open: one row per real tool call, with its target, progress, result and duration, commentary and steers inline. When it settles it becomes one receipt (*2 checks · 1 finding · 12s*) that expands to the same calls.
- **Deterministic results are rendered, not retyped.** A survey becomes its table, coverage and issue summary; a listing becomes rows; a configuration review becomes findings; a fix preview becomes its formats and impact verdict. The window reads `tool_output.detail`; the model interprets it and is instructed not to transcribe the table it already shows.
- **Findings have an evidence chain.** A conclusion carries the Turn's successful checks (most recent eight) as `{call_id, name, target, summary}`. Each finding shows a quiet *2 checks* chip that opens Evidence, or *No direct check* when there was none. This is honest turn-level evidence, never a claim that every call proves every finding.
- **Evidence, not an inspector.** The task side pane is **Evidence**: a human heading, one row per check, the rendered result first, arguments and raw JSON behind a *Raw* fold, attached files, Save report, and usage at the foot.
- **The estate is addressable.** `query_estate` now returns up to 20 notes scoped to the account or bucket being read, plus recent Issue events. The 12-note prompt digest stays; no embeddings, no new table.

## The window

- The five-size type scale is restored to **11 · 13 · 15 · 20 · 28**; the 36px editorial home title is gone.
- Three radii: **6 · 8 · 12**. The canvas is flat; hairline separators and surface steps replace the ambient wash and nested cards.
- The Composer, Home content and Task column share one reading width; the Evidence list wraps long checks instead of clipping them.
- The attention count reads *N open*, so it cannot be mistaken for the number of grouped rows.
- Light, Dark and System remain first-class. English and Chinese have the same keys and the same states.

- No new tool, no route, no migration; schema head stays **2** and the registry stays **15**.

## Upgrading

No migration. Existing providers, estate, notes, tasks and item streams carry over. Storage access remains read-only; fixes remain text the user applies. The new optional `context` on a Direction and optional `evidence` on a conclusion are additive: older items read exactly as before.

Builds are ad-hoc-sealed, not notarized or Authenticode-signed. Verify downloads against the published `SHA256SUMS-*` manifests.
