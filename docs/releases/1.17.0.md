# Storage Agent v1.17.0

**Codex window — quiet chrome, work language, transcript craft. No migration (head stays 030).**

## Summary

v1.16.0 finished the true native Agent; v1.16.1 made tables whole and search honest. v1.17.0 finishes the **window**: UI and UE match Codex's quiet Agent surface — same chrome, same transcript rhythm, same Composer craft — while remaining a storage Agent. The runtime transcript was already Codex-shaped (user bubble, commentary, one *Worked for …* group, `update_plan` card, compacted marker, inline Allow/Deny, Markdown on 46 rem). This release un-paints extra chrome, names Execution not Runs, and matches Codex's quiet bubble, approval, and Worked head.

## Review of v1.16.1 (what this release corrects)

Canonical docs still taught the pre-v1.11 Task (tinted Direction, artifact chips, Review as a sheet). Architecture's banner lagged at v1.10.0 / migration 028. Copy still said *Runs*, *Ask again*, *Your message*. The Composer painted a ContextMeter; Find lived on the title bar and as a document ghost; the empty start had a 30 px glyph. The user bubble and approval card were raised cards. *Worked for {t} · n tool calls* was denser than Codex. A file attached while busy still painted Steer.

Eighteen verified findings (F1–F18) and six workstreams (W1–W6) were the plan in `docs/roadmap.md` before this release. They are delivered here.

## What changed

- **Canonical docs** (`product.md`, `architecture.md`, `CLAUDE.md`, tokens, security, data-model, README): transcript + Artifacts + Allow/Deny truth; architecture banner **v1.17.0 / 030**; day groups are painted; title bar is name + state; tables are whole; documentation contract fails retired IA as current.
- **Work language** (`agentCopy.ts`, `taskCopy.ts`, `i18n.tsx`, `finalize.py`, `prompt.py`): Artifacts section *Execution*; empty fallback invites another Direction; prompt frames Direction / Task / turns; finalize no longer coaches `update_plan`; aria is Direction / Work Result.
- **Chrome** (`Composer.tsx`, `ModelChip.tsx`, `App.tsx`, `TaskDocument.tsx`, `AgentTaskImplementation.tsx`): ContextMeter leaves the Composer bar for the model menu; title-bar Find/palette icons gone; document ghost Find gone; empty-start glyph gone.
- **Transcript craft** (`native-document.css`, `ApprovalCard.tsx`, `WorkedGroup.tsx`, `index.css`): user bubble is a quiet fill; approval is sentence-case hairline *Waiting for approval*; *Worked for {t}* only; Find highlight uses `--selection`; Settings tags are `radius-md`.
- **Composer honesty** (`TaskComposerHost.tsx`, `Composer.tsx`): attachments keyed by task id; a file while busy is labeled Delegate, never Steer.

## Preserved

- One durable Agent Task runtime; one submit path; sequence-only recovery; steer/stop/resume/verify/revisit semantics; read-only allowlist, vault, redaction, server-side scope, bounded/sanitized context, explicit Decisions, no chain-of-thought persistence. No migration. Not a coding Agent: no worktrees, diffs, terminal, browser, or multi-agent orchestration.
