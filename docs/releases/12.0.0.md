# Storage Agent v12.0.0

**One turn, one article.** v12 is an editorial release: the runtime, the item
stream, the 15 read-only tools, the SQLite schema (head **2**) and the safety
floor are unchanged. The window loses its last repeated surfaces and reads a
Turn as a single assistant article.

## One assistant article

- **Request → article.** A Turn is the user's message, then one `<article>`:
  the live trace or a quiet settled receipt (`2 checks · 1s`), the answer, the
  deterministic result of the turn (a survey wins over a narrower view), the
  findings as severity dots, and at most one recorded next step. Nothing is
  painted twice; the receipt no longer expands.
- **One state, one identity.** The title bar no longer repeats a state pill or a
  progress hairline; state lives in the sidebar row, the live trace and Stop.
  The task name appears in the title bar only when the sidebar is collapsed.
- **One Evidence entry, one level.** The findings no longer carry an
  *Evidence · n checks* line. Evidence is the title bar's button: one scroll,
  one row per call, each expands in place to its result and raw data; Save
  report, attached files and folded usage follow. There is no second “call
  detail” page and no Back control.
- **One next step.** Only the first recorded next step is painted, as one text
  line, instead of a three-row suggestions block.
- **Home settles.** The three prompt links are first-run only; after a task has
  been opened on the device, Home is the heading, the estate's attention and
  the same docked Composer. The home content is centred above the dock rather
  than pinned to the top of a mostly empty page.
- **Three Composer controls.** Attach and `@` merge into one `+` menu; the bar
  is `+`, the model chip and Send (or Add to the request plus Stop while live).
- **Less repetition in the estate and Settings.** Bucket configuration groups
  every missing protection into one *Missing protections* row; the safety
  floor is one summary line with its three points folded; Evidence usage is
  folded at the foot.

## Fixed

- **A complete tool result was marked truncated whenever the model's enveloped
  copy was longer than the 24 000-character UI copy.** The window then hid the
  deterministic table and fell back to the model's prose. `detail_truncated`
  now means exactly that the UI copy was cut, so a survey renders its own table
  again. Pinned by `sidecar/tests/test_v1200_release_fixes.py`.
- A list cell in a rendered result separates values with ` · ` instead of
  gluing issue codes together after underscore replacement.
- Durations under one second read `<1s` (`<1 秒`) instead of `0s`.

## What it preserves

One Agent, one submit path, one item stream, the Turn tree, forks,
queue/withdraw, steer/stop/resume, compaction/finalize, the live trace, rendered
deterministic results, all 15 tools, schema head **2**, and the read-only
storage and secret boundaries. No migration; existing providers, estate, notes,
tasks and item streams carry over.

## Install

- **macOS (arm64):** open the .dmg and drag to Applications. On first launch,
  right-click the app → **Open**, or run
  `xattr -dr com.apple.quarantine "/Applications/Storage Agent.app"`.
- **Linux (x64):** `sudo apt install ./storage-agent-v12.0.0-linux-x64.deb`
- **Windows (x64):** run the `-setup.exe`; if SmartScreen warns, choose
  **More info → Run anyway**.
