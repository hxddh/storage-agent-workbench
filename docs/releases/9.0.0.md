# Storage Agent v9.0.0

**Small models work; state stays consistent.** v9 adds no features. It makes the Agent fit the model you actually run, keeps every surface agreeing about your storage, and smooths the places that felt rough.

## The Agent fits small models

- **A lighter first request.** The first request of a survey is about 40 % smaller (≈ 9.1k → 5.4k tokens): tool schemas no longer carry `title` keys or force optional arguments, fixed choices are real enums, and descriptions are one or two sentences. The prompt drops duplicated guidance, and two meta skills (triage, workbench investigation) are gone — their routing is one line.
- **Honest context windows.** The window table picks the longest matching model name (codellama 16k, gemma3 128k, mistral-nemo 128k, qwen3 32k). A local model with no window set is treated as 16 384 tokens, and Settings asks for it, prefilled.
- **Compaction counts everything.** The instructions and tool definitions count toward the window, one tool output is capped relative to it, and small windows keep only the current Direction's outputs whole.
- **Fewer ways to go wrong.** With one storage account, tools use it when `provider_id` is omitted (the scope is still checked on what runs). `survey_account` is always loaded. `record_conclusion` takes findings and next steps only — the answer is the model's own reply; older conclusions still replay and render.
- **One name for each issue.** Review and survey output carry the estate Issue's title and severity, so the answer and the bucket sheet use the same words.
- **Readable tool rows.** "3 buckets, all readable; none public" instead of "3 bucket(s) visible, 3 surveyed…"; every note ≤ 60 characters.

## State stays consistent

- **Verify updates everything.** A verified resolution updates the bucket's recorded configuration, and the home re-reads what needs attention at once.
- **A failure says why.** A failed turn shows the recorded reason and offers *Open Settings*; an interrupted one offers *Continue*.
- **Narrow windows work.** Below 720 px the sidebar starts closed and a tap outside closes it; the side pane covers the page and closes back to the conversation.

## Polish

- **Settings:** saving stays on what you saved, with its connection test; the session token and bucket/prefix scope fold under *Advanced*; the save row stays in reach; Watch sits at the top of an account.
- **Fix panel:** Show fix and Verify stay in place; commands scroll instead of wrapping; the impact is one sentence with its reasons folded; the menu reads *More*.
- **Home:** storage never checked is one line — *acme-prod · not checked yet · Survey*.
- **Tables:** Copy sits in the header row; no size badge over the data.
- **Words:** Chinese field labels, rule titles and durations; the safety points read for people; Details' back link is an arrow; starter chips no longer look pressed; the scrolling page is not a Tab stop.

## Upgrading

No migration; data carries over unchanged. A local model you configured without a context window is now treated as 16 384 tokens — set a larger value in Settings if your server runs one. Nothing about storage access, secrets or bounds changed.
