# Storage Agent v1.00.0

v1.00.0 reconstructs Storage Agent as a modern Agent. It deletes the v0.96
copilot OS product objects that v0.99 only reskinned. No new model
capabilities, no storage tools, no migration (head remains **027**).

## Deleted from the product

- Settings **storage price table**. Settings is model, storage credentials,
  language, and theme. The Sidecar `/settings/price-table` engine API remains.
- Composer **slash SKU catalog** (`/diagnose` `/logs` `/inventory` `/checkup`
  `/cost` `/drift` `/account` `/report`). Typing `/` is ordinary Direction.
  Tools are discovered by the model. Attach stays on the paperclip.
- **First-run wizard.** Empty window is the Composer. Missing model is a
  banner plus Open Settings.
- **4-tab Review destination** and Overview walls (plans, baselines, Drift,
  revisit schedule, decision history). Evidence / Execution / Report open from
  the document as a thin artifact viewer. No header Review button.
- Painted **Verify** control and **revisit** schedule UI. Resume stays when
  the last Execution is interrupted or failed. Decision cards stay.

## Preserved

- One Composer: Delegate / Steer / Stop.
- Agent Task as the application.
- Real Decision gates, queued Direction, Resume.
- Sidecar engines (cost sim, Remediation Plan, baseline/Drift, revisit) with
  no product UI entry.
- Inline deterministic figures and provenance marks in the Work Result.

## Security

Unchanged. No new tools, no migration past **027**.
