# Storage Agent v0.97.0

v0.97.0 is a whole-product UI/UX craft pass. It adds no capabilities, tools,
APIs, or migrations. The Agent Task product model and the v0.96 runtime are
unchanged. The bar is visual and interaction quality: tokens, motion, keyboard,
and designed non-ideal states, judged against Codex/Cursor desktop Agent clients
— while every pixel still only presents runtime-true state.

## What changed

- Complete design-token system (see `docs/design-tokens.md`): color, semantic
  status, type scale, radius, motion, elevation. Dark and light are first-class.
- Core surfaces restyled in place: navigation, Work Result, Execution rows,
  Composer, Decision/Resume/queued cards, Review, Settings. `data-testid`
  contracts, single Composer, and Review's four surfaces are unchanged.
- Unified motion language; skeletons instead of spinners; instant task switch
  from a document cache.
- Command palette covers real actions only (task switch, new, Steer focus, Stop,
  Resume, Review surfaces, theme, language).
- Designed empty/offline/interrupted/history states; EN/ZH copy pass.
- SHOTS gallery expanded to a core-state × theme × language matrix.
- Two known E2E flakes addressed as part of the interaction rewrite: fake-model
  request retries are idempotent; persisted Direction is not also rendered as a
  live pending row.

## Verification performed on the candidate

- Frontend tsc, Vitest (448), production build, Playwright E2E 165 with `retries: 0`, Sidecar pytest 1612, SHOTS 40, and CI desktop builds for macOS arm64 / Linux x64 / Windows x64 were green on PR #202 (`2054c16` and follow-up doc stamps).
- Manual Codex/Cursor side-by-side visual comparison remains a human gate using `frontend/shots/`.

## What did not change

- Runtime, tools, Sidecar APIs, SQLite migrations (head remains **027**).
- Single Agent, single Composer, Focus mode as presentation-only.
- Safety redlines: estimates labelled, gaps explicit, no secrets in the UI.
