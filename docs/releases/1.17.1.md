# Storage Agent v1.17.1

**Patch — queue honesty, Settings container layout, title-bar Find. No migration (head stays 030).**

## Summary

v1.17.0 shipped the Codex window. Using it showed four defects: a just-submitted Direction reprinted as a mysterious Queued bubble, Settings fields squeezed and wrapped wrongly, the window felt sparse, and Find was undiscoverable. This patch keeps the Codex window and fixes those four.

## What changed

- **Queue honesty.** `task.status.queued[]` no longer reprints the execution the client is already following. GET `/agent-tasks` already dropped that row; the SSE fold and `TaskBanners` now do too. A Direction waiting *behind* the current Execution stays visible and cancellable. A `steer_followup` is labeled as itself, not a second Direction.
- **Settings pane.** Provider fields follow the editor (`@container`), not the viewport `sm:` breakpoint. Provider rows wrap on flex-basis. Safety gate names are individual nowrap chips.
- **Find.** Quiet Find and palette icons return to the title bar (⌘F / ⌘K remain). The document ghost Find and empty-start glyph stay gone.
- **Preserved Codex craft.** ContextMeter stays in the model menu; the user bubble stays a quiet fill; *Worked for {t}* stays wall-clock only.

## Preserved

Same runtime, same contracts, same security floor as v1.17.0. One durable submit path. No migration.

## Contracts

- `visibleQueuedExecutions` + `applyTaskStatus` drop the active execution from queued banners.
- Settings grids are `.native-settings-fields` under `@container (min-width: 32rem)`.
- `titlebar-find` / `titlebar-palette` are painted; `task-find-open` and `start-mark` stay forbidden.
