# Storage Agent v1.16.0

**True Native Agent, finished — dict-owned copy, engine discovery in the palette, honest usage end to end, isolated Escape, retried reconnects. No migration (head stays 030).**

## Summary

v1.15.0 made the window native. v1.16.0 finishes it: every user-visible string lives in a dictionary (palette, model chip, triage, shortcuts sheet, sidebar day labels), the command palette names the deterministic engines as prefill actions and hosts the shortcuts sheet entry, token usage renders the persisted governor and memory reuse beside tokens, the context-window denominator is labeled declared-vs-inferred end to end, approvals disambiguate session policy from per-task grants with localized gate names, one Escape closes one layer, view errors dismiss, stalled streams back off and retry, the last-resort boundary follows the theme, and secret shapes match front to back.

## Review of v1.15.0 (what this release corrects)

- **Component-local copy.** Palette, chip, triage, shortcuts and day labels carried hardcoded EN/ZH blocks outside the i18n dict.
- **Engines undiscoverable.** The prompt claimed the palette names the engines; the palette had no engine items. `@` completion and the shortcuts sheet likewise had no visible entry.
- **Usage half-rendered.** `budget_tokens` and `repeat_calls_avoided` persisted for releases but never painted; the window denominator hid its source; the one-time title step was undisclosed.
- **Approval wording.** Session policy vs per-task grant confused; legacy granted rows over-claimed scope; gate action ids rendered as raw snake_case.
- **Keyboard overlap.** One Escape could close both the find bar and the overlay behind it.
- **Sticky errors.** View errors had no Dismiss; offline and model banners stacked.
- **Silent reconnects.** One failed reload went permanently silent; history auto-load had no guard.
- **Themed last resort.** The error boundary was hardcoded dark with a bare reload.
- **Secret drift.** Frontend history shapes lagged the Sidecar redactor; the 413 message said MiB while the Composer says GiB.

## What changed

- **Dict-owned copy** (`i18n.tsx`): `palette.*` (incl. engines + shortcuts), `chip.*`, `triage.title`, `shortcuts.*`; `NAV_DAY_LABELS` in `navigationCopy.ts`.
- **Palette engines** (`paletteActions.ts`, `CommandPalette.tsx`, `App.tsx`, `AgentTaskImplementation.tsx`): engine group with five prefill asks (fills the Composer, focuses, never navigates); window-owned `shortcuts` entry via base actions.
- **Usage, finished** (`lib/usage.ts`, `ContextMeter.tsx`, `types.ts`, `task_runtime/runtime.py`): budget + memory-reuse parts; `context_window_source` (`declared`/`inferred`, additive) labeled in the meter; title-step exclusion disclosed in the tooltip.
- **Approvals** (`ApprovalCard.tsx`, `SafetyPane.tsx`, `i18n.tsx`): per-task grant hinted; session hint disambiguates; gate ids localized with raw fallback; legacy granted claims no scope.
- **Composer** (`Composer.tsx`): `@` hints (with/without files), attachment type errors, history-limit title, `ghu_`/`github_pat_`/`glpat-`/`xoxe-` shapes.
- **Queued editor** (`TaskBanners.tsx`): 32 000 ceiling with counter, matching the PATCH contract.
- **Prompt** (`prompt.py`): tables read-first; chart shape a preference with graceful degradation.
- **Keyboard** (`FindBar.tsx`, `Composer.tsx`, `TaskBanners.tsx`, `App.tsx`): per-layer Escape isolation; disabled Find explains itself.
- **Banners** (`TaskBanners.tsx`, `AgentTaskImplementation.tsx`): Dismiss for view errors; offline suppresses the model banner.
- **Reconnects** (`TaskDocument.tsx`): 2/4/8 s backoff, clear-on-success only; history auto-load guarded.
- **Boundary** (`ErrorBoundary.tsx`): token-driven theme with fallbacks.
- **Server units** (`routers/datasets.py`, `routers/sessions.py`): 413 messages in GiB.
- **Artifacts copy** (`agentCopy.ts`): Runs rename; empty states carry next actions.
