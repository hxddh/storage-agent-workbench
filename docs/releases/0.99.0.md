# Storage Agent v0.99.0

v0.99.0 is an Agent-native surface pass. It adds no model capabilities, no
storage tools, and no SQLite migration (head remains **027**). The Agent Task
product model and the v0.96 runtime are unchanged. The bar is whether the
window reads as **one Task document with one Composer**, judged against Cursor
and Codex: empty window = type in the box; working = the document grows + Steer;
cost/drift readable in the prose and figures of that document.

## What changed

- **One-column document.** Figures sit inline in the Work Result like a code
  block (`max-w` ~46rem). The sticky third-column figures rail is gone. Wide
  windows leave the right half quiet.
- **Review closed by default.** The header button appears only when the Task
  has Evidence, Execution, or other reviewable output. Empty Overview sections
  are not rendered. Four Review surfaces remain the implementation enum.
- **Composer-native first-run.** Missing model is a state of the same box.
  Skip is a one-line resume. First-run never stacks a second Composer.
- **No START FROM HERE cards.** Checkup / cost / drift stay on Composer `/`
  slash commands.
- **No painted Direction / Work Result labels.** Testids remain.
  Typography distinguishes user vs Agent.
- **Header is the task title** (Focus; Review when warranted). Working state
  lives on `agent-live-status`. ⌘K still works; it is not painted. Settings
  stay in the nav footer.
- **One task list.** Needs-you / Running wrappers stay as `display: contents`
  for E2E; section titles are not painted. Row = title + state mark + needs
  badge.

## Copy cuts (v0.99)

- Start heading “Delegate a goal to the Agent” / “把目标交给 Agent” → Composer
  placeholder only.
- “Start from here” suggestion grid → deleted.
- Header “Ready to delegate / Ready for direction · General storage task” →
  deleted.
- Header Connected + painted ⌘K + duplicate settings → deleted.
- Composer “Delegate · Type / for task commands” chrome row → deleted.
- Review empty plan / baseline / drift / summary walls → not rendered.
- Nav “Needs you / Running / Pinned / Recent” labels → deleted.
- Work Result “Artifacts” label → deleted; Evidence / Execution links stay.

## What did not change

- Runtime, tools, Sidecar execution APIs, SQLite migrations (head **027**).
- Single Agent, single Composer, Review four surfaces, Playwright `retries: 0`.
- Safety redlines: estimates labelled, gaps explicit, no secrets in the UI,
  no interpolation of missing data, no chart libraries.
