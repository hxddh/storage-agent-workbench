# Storage Agent v12.1.0

**A quiet start.** v12.1 finishes the subtraction v12 began: Home is one
sentence and one Composer, the estate has one home in the sidebar, and an
answer ends with its findings instead of another prompt. The runtime, item
stream, 15 read-only tools, SQLite schema (head **2**) and safety floor are
unchanged.

## Home is a start

- **One thing to do.** Home is the page's one `<h1>` and the Composer directly
  beneath it. The starter cards, prompt links, readiness paragraphs, account
  lines and Issue table are gone; asking is the first action, not a dashboard
  to scan.
- **Storage has one home.** Accounts, bucket counts, last check, watch state
  and **Needs attention** live in the Storage sheet, opened from the sidebar.
  The sheet's bucket count opens a folded index of every known bucket —
  including a healthy bucket with no Issue — and a bucket opens its own sheet.
- **Nothing needs care** is only said when every account has been checked. An
  unchecked account stays visibly unchecked instead of being counted as safe.

## Answers end with the work

- **No next-step prompt.** The Turn ends with the findings. The recorded
  `next_steps` field remains accepted for older items, but the window and the
  report no longer paint or report it.
- **Readable results.** A survey table is rendered from the tool result, not
  retyped by the model; the duplicate issue summary above it is gone. Inline
  code stays typographic instead of becoming a grey box, and the mobile table
  reads as labelled key/value rows.
- **One article.** The settled receipt, answer, deterministic result and
  findings still read as one article; there is no separate suggestions block,
  evidence line or second result surface.

## A smaller window

- **No startup popup.** Quick Ask is a summoned utility, never a restored
  window. Even a persisted `quick.visible=true` no longer brings it back at
  launch.
- **Quick Ask fits.** It opens at 560×340, with a compact empty state, no
  inherited app menu on Linux/Windows, a top-right close control and Esc to
  hide it.
- **Settings ends with its action.** Save and Delete sit at the end of the
  editor instead of a pinned toolbar; changing section starts at the top.
  Saving still leaves the reader where they moved.
- **The pane does not linger.** Opening a task shows its own Evidence, not an
  old pane left over from Home or another task.
- **Edits keep their context.** Editing a message keeps its estate chips and
  attached files in the fork.

## What it preserves

One Agent, one submit path, one item stream, the Turn tree, forks,
queue/withdraw, steer/stop/resume, compaction/finalize, the live trace,
rendered deterministic results, all 15 tools, schema head **2**, and the
read-only storage and secret boundaries. No migration; existing providers,
estate, notes, tasks and item streams carry over.
