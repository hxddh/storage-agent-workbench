# Storage Agent v8.1.0

**The rest of the review.** v8.1 closes the findings v8.0 left open, adds nothing, and keeps the same native core.

## Fixed

- **Per-turn budgets are exact.** Parallel tool calls run in threads; spending from a budget (e.g. at most 5 notes a turn) is now one locked step, so they cannot overspend together.
- **A stopped or timed-out tool stays quiet.** A tool thread that outlives its Stop or timeout writes nothing after the turn's record closes, and reports no progress after its call settled.
- **Notes are honest when full.** When every slot holds one of your notes, a note the Agent tries to keep is refused and it is told so — before, it was written and trimmed at once while the Agent believed it was kept. Trimming never removes the note just written.
- **Recovery respects where you are reading.** Interrupted work still continues once after a restart, but if you had switched to another version of the task you stay there.
- **Triage proposals name real tools** (`list_buckets`, `review_bucket_config`, `import_evidence`) instead of action types from a removed hand-off.
- **Window:** switching tasks never flashes the previous task; the sidebar and issue menus close on a click outside; storage-preset hints, the account check result, the toast's close button and the chart label are localized; the New task key cap reads Ctrl on Windows and Linux; nine unused strings removed.
- **The live model eval fails without its key** instead of skipping every case and showing green.

Checked and not a bug: deleting a task while it works leaves no error or orphan rows; accepting an already-resolved issue returns it unchanged.

## Upgrading

No migration; data carries over unchanged. Nothing about storage access, secrets or bounds changed.
