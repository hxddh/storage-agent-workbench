# Storage Agent v1.13.0

**Honesty and completeness — every known gap from the v1.12 review closes in one version. No migration (head stays 030).**

## Summary

v1.12.0 made the runtime native all the way through. v1.13.0 makes it honest all the way through: the MCP bridge executes instead of echoing, the OTel export carries real spans, restart recovery covers waiting executions, unknown execution kinds are rejected, compaction chains and triggers without reported usage, the Composer completes `@` files with a redacted history, the palette fuzzy-ranks, approvals project scan bounds, golden evals pin quality, the survey names its bounded fanout, and the updater is wirable from the environment.

## Review of v1.12.0 (what this release corrects)

- **MCP `call` was a stub.** `POST /mcp/tools/call` returned `200 accepted` without executing — the worst kind of dishonesty in this product.
- **OTel export was empty.** The events query named a column that does not exist (`payload_json` vs `payload_json_sanitized`); a bare except turned the failure into `events: []`. No spans existed at all.
- **Restart lost gated actions.** A `waiting` execution's tool thread died with the process, but recovery left it `waiting` — a later Allow settled it completed without the import/scan ever running.
- **Unknown kinds silently downgraded.** A misspelled execution `kind` ran as an ordinary investigation.
- **Compaction needed reported usage.** Gateways that never report usage left auto-compaction permanently silent; CJK estimates were 4–8x optimistic; summaries did not formally chain.
- **Capability memories never cleared.** A fixed proxy waited for a Sidecar restart to be retried.
- **Composer history stored secrets.** Plaintext localStorage kept whatever was pasted, including key material.
- **No `@` references.** Files could only be attached, never named.
- **Palette was substring-only.** 30+ tasks stayed `O(n)`.
- **Large-scan cards hid the estimate.** Buckets and estimated live calls never reached the card.
- **No evals.** The golden-cases skill was prose, not a gate.
- **Fanout unnamed.** The survey's bounded parallelism had no pinned design.
- **Updater unwirable.** No path from key material to a live updater without editing source.
- **Packaging smoke informational everywhere.** A broken bundle could ride a release branch.

## What changed

- **Real MCP dispatch (W1).** The stateless allowlist (29 tools) executes through the S3 layer with scope/input clamps, recorded via `run_tool`. Session-bound tools are out by design (stateless bridge). `GET /mcp/client/status` reports the consuming side as disabled-by-design with the threat-model pointer (`docs/security.md` appendix).
- **OTel spans (W1).** Deterministic `trace_id`/`span_id` + W3C `traceparent` per span, no migration; failure path logs instead of emptying.
- **Recovery truth (W2).** `waiting` → `interrupted` on restart (Decision survives; Resume re-plans). Unknown `kind` → 422. Cancelled resume → `kind=retry`/`[retry]`. `waiting` rides the heartbeat branch, not the 2 s recheck.
- **Scope/bounds truth (W3).** One scope function everywhere, list clamps on all paged tools, plural secret keys, range/preview budgets verified as bounds (synthesize note, never a Decision).
- **Context staying power (W4).** Usage-less trigger fallback, CJK-weighted estimates, chained summaries, 5 s `AGENTS.md` cache, capability reset on green provider test.
- **Tool-row truth (W5).** Optimization tools emit full activity rows.
- **Composer truth (W6).** `@` file completion from the Task, redacted history (key-material entries dropped, values masked, pre-v1.13 entries migration-cleaned on read), fuzzy palette, per-execution detail pages (`events-page`), 200-message cache bound, 90 s long-run hint.
- **Approval truth (W7).** Large-scan cards show buckets + estimated live calls; preview/range budgets pinned as bounds-not-gates by test.
- **Evals (W8).** `test_v113_eval_golden.py` + `docs/evals.md`.
- **Release truth (W9).** Updater wired from `TAURI_UPDATER_PUBKEY`/`TAURI_UPDATER_ENDPOINTS` (both-or-neither, loud fail); packaging smoke required on `release/*`.
- **Named fanout (W10).** `_PROBE_WORKERS = 4` pinned, `fanout_workers` in the survey result, single-row merge tested.

## Preserved

- One durable Agent Task runtime; one submit path; sequence-only stream recovery; steer/stop/resume/verify/revisit semantics; runtime titles; reasoning effort; transcript turn, inline approvals, Artifacts panel.
- Read-only allowlist, vault, redaction, server-side scope, bounded/sanitized context, explicit Decisions, no chain-of-thought persistence. No migration.
