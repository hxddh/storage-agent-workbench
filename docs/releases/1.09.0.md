# Storage Agent v1.09.0

**Native Agent window — full teardown of the v1.04–v1.08 chassis. No migration (head remains 027).**

## Summary

v1.09.0 removes every element of the v1.04–v1.08 presentation and rebuilds the frontend as one native Agent window in the shape of a modern coding agent: a sidebar, a window title bar, one Task document, and one Composer. The activity bar, status bar, Details inspector, warm-orange token system, magazine empty state, and the marketing copy that had leaked into chrome are gone. The durable runtime, the read-only tool floor, and the Direction → Execution → Decision → Work Result → Artifact model are unchanged.

## Review of v1.08.0 (what this release corrects)

- **A web-app chassis in a desktop window.** A 44px activity bar, a 22px status bar reading `Storage Agent · warm editorial · Codex native`, and a static 280px "Details" panel that painted a keyboard legend (`⌘K`, `⌘N`, `⌘B` …) — the legend CLAUDE.md forbids — around the Task.
- **Broken E2E contracts.** The v1.07 "Ask anything" placeholder contradicted `first-run`, `start-surface`, `zh`, and the visual-review gallery, all of which assert *Give the Agent a goal* / *给 Agent 一个目标*.
- **English hard-coded in chrome.** Title bar status, "Details", "No task selected", "Task open", "N tasks", and the Composer's `Steer` / `Stop` in Chinese all bypassed i18n.
- **Dead code shipped.** `EvidenceActivity.tsx` was imported by nothing and styled by nothing.
- **Six overlapping CSS layers** (`agent-shell`, `agent-state`, `agent-runtime`, `agent-task`, `work-result`, `execution-review`) with `!important` cross-overrides.

## All elements rebuilt

- **Window** — `sidebar · title bar · document`. The title bar carries the task name and its real state (Working pulse / Needs decision / Needs attention) and, when the sidebar is collapsed, the sidebar toggle and New task. The packaged macOS shell keeps room for the native traffic lights.
- **Sidebar** — window chrome row, **New task**, one chronological title list (state as a row mark; Ready paints nothing; relative time on hover), **Settings**. Rename / Delete behind one More control. Collapses to zero width; resizable 208–420px.
- **Tokens** — one achromatic surface ladder (`#0f0f0f → #333333` dark, `#ffffff → #dadada` light), an ink primary (`#ececec` / `#0d0d0d`), hairline depth. Status is the only colour. All contrast, ladder, hue and focus-ring tests pass on the new values.
- **Empty start** — one greeting line (*What should the Agent work on?* / *让 Agent 处理什么？*) and the Composer in the middle band. No hero, no cards.
- **Composer** — 24px-radius container, `+` attach, textarea, **model chip** (backed by `/model-providers`; switching activates a provider server-side; *No model* opens Settings), round ↑ send at rest; ↑ Steer + ■ Stop while working. Placeholders restored to the contract.
- **Direction** — a quiet tinted block on the 46rem measure; copy on hover; long input folds.
- **Execution** — one **Worked for 12s · 3 tool calls** group per Work Result with real tool rows (✓/✕ glyph, mono tool name, target, result, duration); *Working* shimmer while live; rows visible by default, header folds a finished trace, failures never fold away.
- **Work Result** — a page, not a card: prose on the 46rem measure, data on the 64rem track sharing the left edge, Evidence / Execution / Report chips and copy below.
- **Decision** — an approval card: eyebrow, title, why, impact table (scope, scan, will-move), **Approve** / **Decline**.
- **Review** — a sheet from the right with hairline, scrim and slide; title + close + artifact.
- **Settings** — a centered dialog with sections General (theme / language) · Model Providers · Cloud Providers · Skills & bridges · Safety.
- **Palette, shortcuts sheet, toasts, find bar, buttons, inputs** — restyled on the new tokens; one icon set (`components/icons.tsx`).
- **Copy** — every string in chrome goes through i18n; Chinese parity restored.

## Preserved

- `Agent Task is the application` — Direction → Execution → Decision → Work Result → Artifact.
- Durable `task_executions + execution_events after=<seq>` + `task_context_versions` + Steer / Stop / Resume / queued Directions.
- Read-only allowlist, vault, redaction, server-side scope, confirmation gates. No new tools, no destructive S3, no generic shell, no migration past **027**.

## Contracts

- `architecture.test.ts` rewritten for the v1.09 file set (physical removal of every earlier shell and CSS layer; window composition; sidebar; Composer + model chip; document renderers; Decision; Review sheet; Settings dialog; tokens).
- `legacy-ui-contracts.test.ts` and `e2e-contracts.test.ts` now also reject the v1.0x activity bar, inspector, status-bar copy and drawer title.
- `theme.tokens.test.ts` accepts an achromatic ladder while still rejecting mixed hues.
- E2E: settings selectors moved to `settings-dialog`; the start surface asserts the middle band and the model chip; the visual-review gallery header is v1.09.0.
