# Storage Agent v0.93.0

v0.93.0 rebuilds Storage Agent around an Agent-native task model. The Agent task is now the application: delegation, execution, steering, durable results, evidence, and review stay in one continuous workspace instead of being split across a chat shell and application-level investigation pages.

## Agent-native task workspace

- Replaces the v0.92 Investigation / Timeline / Evidence / Runs / Report application IA with a single active Agent Task workspace.
- Replaces investigation history with an Agent Task command center that exposes live `Working`, `Needs attention`, and `Ready` state, task scope, and durable outputs.
- Keeps background Agent execution attached to its task when the user switches to another task, then reconnects to the same live or durable work when reopened.
- Keeps Review contextual to the active task. Evidence, Execution, and Report are Agent outputs and artifacts; they no longer replace the task as top-level work surfaces.
- Adds Focus mode without creating a second task or review lifecycle.

## Direction, Execution, and Work Result

- Replaces chat-bubble semantics with Agent task primitives:
  - **Direction** for the user's objective or steering input.
  - **Execution** for real tool activity and analysis work.
  - **Work Result** for the Agent's durable output.
  - **Artifact** for durable evidence and reports produced by the task.
- Keeps structured S3 errors as first-class storage error artifacts instead of flattening them into prose.
- Keeps execution provenance, grounding, persisted call input/output, metrics, and report generation attached to the work that produced them.
- Keeps long task history pageable and searchable without turning the main work area into an observability wall.

## One real Agent control path

- The product now exposes one Agent Composer only.
- Idle state is explicit **Delegate**: give the Agent a goal, problem, or job to complete.
- In-flight state is explicit **Agent working**, with real **Steer** and **Stop** controls backed by the existing turn runner.
- Steering changes the direction of the active execution without inventing a separate chat or task.
- Model/provider selection is secondary configuration rather than the primary interaction model.

## Real execution, not simulated Agent chrome

- Live Agent state comes from the real per-task execution store and real streamed tool activity.
- v0.93.0 does not invent plan steps, fake agents, worktrees, or unsupported parallel workers.
- Multiple tasks may remain independently active because execution ownership is keyed to the durable task/session rather than the currently visible viewport.
- Attached inventory and access-log evidence continues to run through the real Sidecar analysis path.

## Safety and evidence contracts preserved

- Cloud credentials and secret values remain excluded from model prompts and browser-visible API payloads.
- Cloud capabilities remain read-only by default.
- Data-moving or bounded evidence-import operations keep their existing approval requirements.
- Auditability, durable memory, evidence truth, execution details, and report provenance remain intact through the UI rebuild.
- Offline S3 error triage remains available without a configured model provider.

## Architecture cleanup

The rebuild physically removes the v0.92 UI ownership boundaries rather than hiding them behind new styling, including the old Investigation navigation, application-level Surface tabs, secondary Steering surface, legacy SessionRail adapter, and Inspector overlay path. Architecture regression tests prevent these patterns from returning.

## Product identity

- The desktop product, window title, first-run experience and release downloads are now **Storage Agent**.
- The historical repository/crate and bundle identifier remain stable where changing them would break update or platform identity contracts; they are no longer exposed as the product name.

## Quality gates

The release is gated on the full repository matrix: frontend typecheck/lint/unit/build, Sidecar tests, packaged Sidecar smoke, real-Sidecar Playwright E2E, visual-review screenshots, and macOS Apple Silicon / Linux x64 / Windows x64 desktop builds. The E2E suite covers task delegation, background execution, steering, stop, durable multi-turn work, evidence attachments, real storage calls, reports, task navigation, contextual Review, accessibility, dark/light contrast, and Chinese localization.

Desktop artifacts are distributed unsigned/ad-hoc as documented by the build workflow. Verify the platform-specific `SHA256SUMS-*` file before installation when artifact integrity matters.
