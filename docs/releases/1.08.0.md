# Storage Agent v1.08.0

**Codex full replica — native teardown. No migration (head remains 027).**

Thorough Codex/Cursor native rebuild: shell becomes truly native, Work Result becomes editorial page, Composer becomes Cursor-like, Inspector becomes contextual.

## All elements rebuilt

- **Native shell** — `titleBarStyle: overlay` + `hiddenTitle` + `trafficLightPosition 12,12` + vibrancy. Title 13px semibold -0.01em left-aligned. No painted `⌘K/⌘N/⌘B` legend in chrome — shortcuts remain keyboard-first.
- **Activity bar** — 44px, 32px hit, 1.5px accent indicator, gap-0.5 py-1.5, 16px optical icons. Always visible, navigation collapses to it.
- **Work Result** — no longer a card in a canvas: hairline-only depth (`border` not `shadow`), editorial `46rem` prose `15px/1.8` + `64rem` wide tables sharing left edge, display `400 -0.02em`, code `93%` JetBrains Mono, tabular-nums tables. Star header weight 400, not bold.
- **Composer** — Cursor-like: ghost `h-7 w-7` paperclip, unified `32px` orange pill `13px medium`, ` ↑` history (last 20 prompts), `Enter` delegate / `Shift+Enter` newline, grows `44→240px` with iOS spring. No `transition-all`.
- **Inspector** — 280px contextual (not static): Task provenance, recent tool trace, findings when available. Collapsible, hairline, quiet. Review overlay remains for deep Evidence/Execution/Report.
- **Explorer** — quiet chronological list stays (Rename/Delete), but `⌘K` is now primary switch via palette; type-ahead travels through `CommandPalette` fuzzy.
- **Motion** — iOS spring `0.16,1,0.3,1 120/180/240` exclusively, no `translateY(4px)` fade. Only `background/border/transform/opacity` transition.

## Preserved

- Read-only allowlist, vault, redaction, scope, confirmation gates.
