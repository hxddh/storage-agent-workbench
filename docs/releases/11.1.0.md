# Storage Agent v11.1.0

**The window, made quiet.** v11.1 is a presentation release. The runtime, item
stream, 15 read-only tools, schema and safety floor are unchanged. The window
was rebuilt around one document instead of a stack of cards.

## One document

- **Only six surfaces**: the Composer, menus/popovers, toasts, the side pane,
  the Settings dialog and code blocks. Content — findings, suggestions,
  attention rows, Issues, notes, configuration, figures — carries hierarchy in
  type, space and hairlines, not in borders, radii or backgrounds.
- **Cool graphite and white**, one blue accent, no warm-paper/blue temperature
  clash. The accent marks only action, selection, focus and live work.
- **A calmer scale**: 11 px meta, 13 px interface, 15 px reading, 20 px focal,
  24 px page title. No uppercase micro-labels. A 240 px rail, a 704 px reading
  column, a 44 px title line and a 380 px side pane.
- **A quieter Composer**: 1 px neutral border, no glow, one small accent send
  control. The same input sits in the same place on Home and every Task.
- **Content first**: findings are a flat list with a severity dot; the turn's
  successful calls are said once after the list as *Evidence · n checks*, not
  repeated on every row. Suggestions are quiet rows, not cards. The result
  table has a header rule and row rules, not a card around it.
- **Settings fits its content** instead of being a mostly empty modal. The
  mobile layout stacks prompt links, keeps message actions out of the answer,
  and removes the dead gap above the Settings content.

## What it preserves

One Agent, one submit path, one item stream, the Turn tree, forks,
queue/withdraw, steer/stop/resume, compaction/finalize, the run trace, rendered
deterministic results, turn-level Evidence, all 15 tools, schema head **2**, and
the read-only storage and secret boundaries. No migration; existing providers,
estate, notes, tasks and item streams carry over.

The hierarchy follows the current agent products rather than their chrome:
Codex's one document and bottom Composer, Cursor's inline context and compact
tool rows, Qoder's single conversation plus a task monitor only when needed. It
does not take an IDE file tree, task cards, a plan canvas or a second navigation
tree.

## Install

- **macOS (arm64):** open the .dmg and drag to Applications. On first launch,
  right-click the app → **Open**, or run
  `xattr -dr com.apple.quarantine "/Applications/Storage Agent.app"`.
- **Linux (x64):** `sudo apt install ./storage-agent-v11.1.0-linux-x64.deb`
- **Windows (x64):** run the `-setup.exe`; if SmartScreen warns, choose
  **More info → Run anyway**.
