# Storage Agent v0.98.0

v0.98.0 is a content-presentation pass. It adds no model capabilities, no
storage tools, and no SQLite migration (head remains **027**). The Agent Task
product model and the v0.96 runtime are unchanged. The bar is whether the
product's real outputs — cost, drift, findings, evidence — can be read in five
seconds and traced in one click, judged against Codex/Cursor desktop Agent
clients.

## What changed

- Deterministic SVG figures from runtime artifacts (cost horizons, independent
  inventory age/class, Drift classes, access-log mix). No third-party chart
  library. Coverage and “estimate” sit on every figure. Gaps are gap states.
  Unconfirmed price table → cost axis withheld; class mix may still plot.
- Finding/figure provenance: `GET /agent-tasks/{id}/provenance` projects
  existing finding refs, tool calls, and artifacts. Hover preview; click opens
  Review Evidence anchored to that finding. Missing chain is labelled.
- Subtraction: 46rem reading column + figures rail on wide windows; start
  suggestion cards; Review Overview hierarchy; Needs-you badges; palette group
  headings; copy cuts listed in the PR.
- Inline first-run on the start surface (not a modal destination): welcome →
  model (real create + test) → storage (skippable, skip is a designed gap) →
  first checkup. Every step can exit; empty start offers resume.

## Copy cuts (v0.98)

- Start description → “Name the job and what done looks like.”
- Resume body → one sentence.
- Live steer hint → “Steer anytime”.
- Review empty artifacts / baseline / summary lines shortened.
- Evidence activity blurb shortened.
- Review overview dropped the findings/executions/memory count row (v0.97 leftover).

## What did not change

- Runtime, tools, Sidecar execution APIs, SQLite migrations (head **027**).
- Single Agent, single Composer, Review four surfaces, `data-testid` contracts,
  Playwright `retries: 0`.
- Safety redlines: estimates labelled, gaps explicit, no secrets in the UI,
  no interpolation of missing data.
