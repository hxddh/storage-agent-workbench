# Storage Agent v14.0.0

**One window. One Composer. The answer first.**

v14 removes the last second surface and the last second layout. Quick Ask and the
separate Home component are gone: Home is the same workspace before its first
Direction. A Turn now reads as one conversation — what was asked, the work it
caused, the answer, its findings, then deterministic data in a quiet fold. Long
tasks open on a bounded page and load older Turns on demand. The shell keeps its
Sidecar alive. Dependencies are current.

## The window

- **One window, one Composer.** The small always-on-top window, its `?view=quick`
  entry, its shortcut, tray item and `hide_quick` path are deleted. `⌘⇧S`
  summons the one window and focuses the Composer.
- **Home is an empty Task.** One small Agent mark, one heading, and the Composer
  directly beneath it, centred as one block. No hero, starter cards, readiness
  sentence, account lines or Issue table.
- **A Turn is answer-first.** The objective, one clickable receipt
  (`2 checks · 1s`), the answer, findings, then the deterministic result in a
  **Data** fold. A fix opens by default because it is the deliverable. The
  running call is the one live head line; calls that already returned follow it,
  so no call is painted twice.
- **Evidence is human first.** A meta line, one row per call, a compact result
  summary and arguments/output behind **Raw**. The full table belongs to the
  task's Data fold.
- **Quieter surfaces.** A 28 px page title, 14 px Composer and pane radius, a
  warmer graphite/paper ladder, and wider table rows. One accent; no nested
  cards, no decorative wash.
- **Files upload honestly.** Real progress, a cancel control, a failed first
  upload removes the empty task it created, and the timeout matches the real
  upload path.

## Reliability and scale

- **Bounded snapshots.** `GET /tasks/{id}` returns the newest 60 Turns and
  `has_older` / `oldest_turn_id`; `GET /tasks/{id}/history` pages older Turns
  with their items. The reader keeps the head and prepends without reordering.
- **A supervised Sidecar.** The Tauri shell restarts the Python process on the
  same port and token if it exits; an 8-second health poll reconnects, reloads
  the task and clears **Runtime offline** without relaunching the app.
- **No dead end on a failed snapshot.** The task loads with backoff and offers
  *Try again* instead of opening an empty stream.
- **A bounded model call.** One model step times out at 180 s instead of 600 s,
  so a dead endpoint becomes a recorded failure rather than a ten-minute wait.
- **Localized transport errors.** Offline, timeout, auth, busy, server and
  file-too-large failures read as one sentence in English or Chinese; backend
  validation details are kept because they name the field to fix.

## Data

One append-only migration, head **3**: `v14_retire_quick_ask_origin` turns any
retired `quick_ask` task into an ordinary `user` task. Existing tasks, items,
connections, estate, notes and files carry over. One read-only history route was
added; the registry remains **15 read-only tools**.

## Removed

- The Quick Ask window, its deep-link hand-off, tray/menu entries, shortcut and
  CSS.
- The separate Home component and its layout.
- `TaskIn.origin`, `TaskIn.context`, `TurnIn.context`, `user_message.context`
  and the `[Context: …]` replay.
- `conclusion.answer` and `conclusion.next_steps` from writers, readers, the
  report and the schema. Old items are ignored, not re-interpreted.
- Retired tool labels and skill aliases: a skill loads only by its exact card
  name.
- Unused estate client methods and types; the estate is reached through the
  Agent and the watch-only Settings control.
