# Storage Agent v1.04.0

v1.04.0 is the **Codex/Cursor native rebuild** — a calm, editorial, native agent. Warm, not cold. One accent voltage, hairline depth, and a document that reads like a well-set technical paper. No new storage tools, no migration (head remains **027**).

## Changed — warm editorial tokens

- **Warm charcoal dark** `h=32` (`#141210` ladder, 12.3 L* span, `dL*≥2.5` per step) and **warm cream light** (`#fff9f0` ladder) replace the cool `h=268` technical grey. The ladder still clears the same floor, but it now reads as warm native chrome.
- **Single-voltage orange** `-[#ff6b35/#c73a00]` (4.97:1 on `--hover`, 5.20:1 as ink) replaces the pervasive blue. Blue is kept as `--viz-1` for data, not for chrome. `Mac` and `Windows` now share one warm accent.
- **Hairline-only depth** (`--shadow-elev` as `0 0 0 1px var(--edge)`) replaces `8px/28px` scrims. Cards float on 1px borders, not shadows.
- **Display at weight 400** with `-0.02em` tracking and `1.8` leading — a quietly-confident magazine voice, never bold. Rank comes from size, tracking, and space.
- **iOS spring** (`cubic-bezier(0.16,1,0.3,1)`, 120/180/240) replaces the web default. Composer slides 4px, Review scales 98→100.

## Changed — Codex/Cursor layout

- **Icon bar** `56px` (Cursor activity bar): `+` New, `⊞` Explorer, `⌘K` Palette, `◫` Details, `⚙` Settings — always visible, even when the explorer is collapsed.
- **Collapsible 260px Explorer** (true explorer, not a queue): slides out from the icon bar, holds the chronological task list. `⌘B` toggles, `j/k` still walks the document.
- **Details 240px** (Xcode inspector, not an overlay): shows Task/Shortcuts/Model, `Esc` closes, `⌘B`/`◫` toggles. The old overlay Review is now a native inspector.
- **Native title bar** `28px` (vibrancy, `Storage Agent · Ready/Starting/Offline` + `⌘K`/`⌘N` hints, `data-tauri-drag-region`) and `22px` status bar (`tasks · task / local-first · read-only`).
- **Center 46rem document**: no header, no status strip, no second presentation mode. Sticky Composer, hairline dividers, 1px borders.

## Changed — Cursor-like Composer + editorial Work Result

- **Composer** `44px` min, `px-4/py-3.5`, `rounded-2xl`, `shadow-elev` + `focus-within:shadow-pop`, `16px` paperclip, `text-base leading-6`, `240px` max, unified `Delegate` (orange pill with send icon) vs `Steer+Stop` (orange + canvas secondary), `5s` virtual-time-budget, `focus-within` hairline glow.
- **Work Result** `46rem` card (`rounded-xl border-edge shadow-elev px-5 py-5`), `7×7` orange star header, `prose max-w-none`, artifact nav as pill buttons (`Evidence/Execution/Report` with accent count badges).
- **Direction** as `rounded-xl border-edge bg-panel/50 px-4 py-3` with `2xs uppercase tracking-widest` label and `1.5px` accent dot.

## Preserved

- `Agent Task is the application`. One `Delegate / Steer+Stop`, durable `task_executions` + `execution_events` (`after=<seq>`), `task_decisions`, `work_results`, `task_artifacts`, `task_context_versions`.
- `v1.03` gated extensions: local models (`ollama` etc.), user skills (`GET /skills`), read-only MCP (`STORAGE_AGENT_ENABLE_MCP=1`), observability (`GET /export/otel`), OS shell (dialog/notification/opener/deep-link/global-shortcut/updater).
- Read-only storage tools, no shell/raw boto3/fs, secrets only in vault, server-side scope, explicit Decisions, bounded/sanitized context, no CoT.

## Security

Same floor. No new tools, no migration past **027**. Warm tokens still clear WCAG AA (4.96+ on worst surface) and `dL*≥2.5`.

## Known limitations (unchanged)

- Apple notarization / Windows Authenticode / trusted auto-update chain not yet configured (updater gated).
- macOS x64/universal not produced; Linux/Windows experimental where noted.
