# Storage Agent v1.16.1

**Patch — tables render whole, search counts what it finds, wrapping and layout honesty, Codex-grade polish, green CI. No migration (head stays 030).**

## Summary

v1.16.0 finished the native agent but left three user-visible defects and a red CI: tables could still spill sideways (intrinsic min-content ignores `break-word`), find counted folded rows it could not show, and unbreakable runs stretched the whole column past the window — which one layout gate was passing vacuously. This patch fixes all three, replaces mid-word breaking everywhere, applies a Codex-grade polish pass, and repairs every rotted E2E/screenshot assertion so CI is green again.

## What changed

- **Tables render whole.** Pagination, inner scroller and sticky header removed; `table-layout: fixed` so intrinsic min-content cannot spill; cells wrap at word boundaries.
- **Search counts what it finds.** Worked groups unfold while a runnable find query is open (folded rows are unmounted); the task scroller moves by measured offset instead of `scrollIntoView` into nested scrollers.
- **Layout honesty.** `min-w-0` on the task root, column, footer and bubble — flex `min-width: auto` stretched the column to 3035 px on ARNs and long tokens.
- **Wrapping.** `overflow-wrap: anywhere` replaced by `break-word` everywhere (mid-word breaks).
- **Polish.** 40 px title bar, 36 px sidebar rows, bordered menus, airier Composer/bubble/approval/banner/plan/table, unified bubble corners, palette selected ring, empty-start mark.
- **CI green.** Rewrote rotted E2E and screenshot assertions to current copy and behavior (placeholders, removed sidebar fact, whole-table contract).

## Preserved

Same runtime, same contracts, same security floor as v1.16.0. No migration.
