# Storage Agent v1.02.0

v1.02.0 finishes the native Agent window. v1.01 removed the workbench shell;
this release removes the leftover chat transcript. No new model capabilities,
no storage tools, no migration (head remains **027**).

## Deleted from the product

- **`"New chat"`** as a default Task title. An unnamed Task is **Untitled**.
- **`thread.*` error keys.** Provider/runtime failures use `task.*` copy.
- Dead **`.thread-prose` / `.thread-bleed`** layout CSS and Thread comments.
- Persistent Composer **keyboard legend**.
- Painted **⌘N** on New task. The shortcut remains.
- Decorative **empty-state illustration** in the task list.

## Changed

- Working rows say the Agent is working on the Task, not a chat-era
  "still running" line.
- Composer is attach + textarea + Delegate / Steer / Stop.
- Live Execution is not kept on screen after the current Work Result persists.
- Architecture, legacy, and documentation contracts describe v1.02.

## Preserved

- One Composer: Delegate / Steer / Stop.
- Agent Task as the application.
- Overlay Review, j/k `scrollTo` + follow-release, real Decision gates.
- Sidecar engines with no product UI entry.
- Read-only storage tools. Migration head **027**.

## Security

Unchanged. No new tools, no migration past **027**.
